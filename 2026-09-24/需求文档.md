# 黄油资源聚合爬取工具 — 需求说明书

> 本文档用于**从零开始**实现该工具，读者是接手开发的 AI。
> 文中「待确认」标注的点，实现前需与需求方确认；括号内为可先采用的默认建议。
> 目标：交付一个本地可运行、带 Web 界面的完整工具，并附一键启动脚本。

---

## 1. 项目目标

做一个**本地运行**的黄油资源聚合爬取工具：

- 从若干 ACG 站点抓取帖子；
- 只保留带真实下载链接的资源；
- 按热度排序后，以 HTML 卡片形式展示；
- 支持一键导出 / 下载离线 HTML 文件。

---

## 2. 技术栈与运行方式

| 项 | 要求 |
|---|---|
| 前端 | HTML + 原生 JavaScript（单页，无外部框架 / 构建工具） |
| 后端 | Python + Flask |
| 数据存储 | SQLite（本地文件即可） |
| 任务执行 | 支持后台爬取 + 前端实时看进度 + 随时停止 |
| 启动 | 提供 `start.bat`，双击即可启动并自动打开浏览器 |

## 4. 爬取内容（每个帖子需抓取的字段）

| 字段 | 要求 |
|---|---|
| 标题 | 保留原始标题（含 `【PC/...】` 这类前缀，不要剥离） |
| 平台类型 | 从标题前缀判断：`【PC+安卓/...】` → PC+安卓；`【PC/...】` → PC；`【安卓/...】` → 安卓；无前缀 → 未知 |
| 所有图片 | 抓取帖子全部图片；过滤掉头像、表情、Logo、缩略图占位图；按原文顺序去重 |
| 网盘链接 | **只保留两种**：百度网盘、移动云盘；同时解析出提取码 |
| 解压码 | 从正文"解压密码 / 解压码"附近提取 |
| 作弊码、解压步骤、PS 等 | 待确认：是否作为独立字段单独展示，还是整段存入正文即可 |

---

## 5. 网盘过滤规则（核心）

- 一个帖子**必须至少含一个**百度网盘或移动云盘下载链接；
- 两种都没有的帖子 → **直接跳过，不爬**；
- 可选「双网盘模式」：开启后必须**同时**含百度 + 移动云盘（默认关闭）。

---

## 6. 两种爬取模式（两个板块）

| 板块 | 说明 |
|---|---|
| 按日期爬取 | 支持「单日（最近 N 天）」和「多日（起止日期范围）」两种 |
| 按页面爬取 | 待确认：是指"抓指定站点的前 N 页"，还是"从某个页码开始翻页"？ |

> 两个板块不在同一页面同时显示，避免并发任务互相干扰。

---

## 7. 前端页面与交互

- **实时进度**：爬取过程中，前端实时显示后端爬取日志 / 进度 / 每条帖子的状态。
- **结果展示**：爬完后自动转成 HTML 卡片视图，每个卡片显示——标题、来源站点、平台标签、**全部图片完整渲染**、网盘按钮、解压码、删除按钮。
- **原帖按钮**：每个卡片提供"原帖"入口，点击直达源帖页面。
- **平台过滤**：可只看「仅 PC」或「仅 PC+安卓」。
- **导出下载**：一键下载爬取结果生成的 HTML 文件。
- **停止按钮**：爬取过程中可随时终止。
- **历史记录**：每次任务留档，可回看 / 再次下载 / 删除。

---

## 8. 排序推荐规则

按「点赞数 + 评论数」综合排序（权重待确认）。
> 待确认：此前项目一度改为「仅按点赞数」排序；新项目采用哪种，需与需求方确认。

---

## 9. 导出 HTML

- 生成两个独立单文件 HTML：`PC.html`、`PC+安卓.html`（固定文件名，覆盖式，不带时间戳）。
- 单文件内嵌 CSS；图片用相对路径引用，保证离线用 `file://` 打开也能看图。
- 卡片网格布局，顶部含生成时间、统计数字。

---

## 10. 反爬与稳定性

- 限制请求频率（单请求间隔随机 1~2 秒）、全局并发不超过 4；
- 失败重试（最多 3 次，指数退避）；
- 单帖失败不中断整体，记日志后跳过；
- 服务端请求 URL 前强制校验：只允许 http/https，拒绝 localhost / 环回 / 私有 / 保留地址（防 SSRF）。

---

## 11. 一键启动 `start.bat`

要求脚本完成：检测 Python 是否安装 → 安装依赖 → 启动 Flask → 自动打开 `http://127.0.0.1:5000`。

1. 「按页面爬取」的具体语义（前 N 页 / 从某页起翻页）？

3. 排序采用「点赞 + 评论」还是「仅点赞」？

---

## 13. 验收标准

- 双击 `start.bat` 即可运行，浏览器自动打开界面；
- 能按日期 / 按页面发起爬取，前端实时看到进度；
- 爬取结果正确过滤：无百度 / 移动云盘的帖子不入库；
- 结果按约定规则排序展示，每卡片含原帖按钮；
- 可一键下载 `PC.html` 与 `PC+安卓.html`，离线打开能正常看图。
