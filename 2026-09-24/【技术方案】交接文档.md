# 【技术方案】交接文档

类型：项目开发

## 〇、协作约定
本文档用于「交接文档驱动」的跨对话协作，所有状态以本文档为准。
- 用户说"阅读交接文档，准备开始"或意思相近的说法 → 按开场协议执行
- 用户说"对话结束，总结项目"或意思相近的说法 → 按收尾协议执行
- 开场协议：①用3~5行概括对目标/进度/关键结论的理解 ②列出下一步待办并给建议 ③有明确风险才单列
- 收尾协议：①把一~八板块更新到最新状态 ②把本次对话中用户新告知的信息追加到「九、对话信息记录」

## 一、背景与目标

### 项目定位
本地运行的ACG黄油资源聚合爬取工具，从5个网站抓取游戏资源，生成可离线浏览的HTML卡片页面。

### 目标网站（5个）
| 序号 | 网站 | 域名 | CMS | 爬取难度 |
|------|------|------|-----|----------|
| 1 | ACG游戏姬 | www.acgyxjvip.com | WordPress + Lolimeow | ★☆☆ 低 |
| 2 | 萌幻ACG | bbs4.acgrx.com | Typecho + MiKu | ★☆☆ 低 |
| 3 | ACG图书馆 | acgll.xyz | WordPress + Zibll 8.8 | ★★☆ 中 |
| 4 | ACG俱乐部 | www.acgjlb.cc | 待确认 | ★☆☆ 低 |
| 5 | 鲲Galgame | www.kungal.com | Nuxt3 SSR + JSON API | ★★☆ 中（接口好爬，但下载链接需登录 cookie） |
| ~~IACG.RIP~~ | ~~community.acg-c.net~~ | ~~Flarum~~ | ~~★★★ 高~~ **暂不爬取** |

### 核心功能
1. 按日期爬取 / 按页码爬取
2. 只保留含百度网盘或移动云盘链接的帖子
3. 图片下载到本地，HTML离线可用
4. 按点赞+评论排序（萌幻ACG无数据则随机）
5. 生成 PC.html 和 PC+安卓.html
6. Web界面：实时进度、卡片展示、历史记录

## 三、数据模型

### posts 表
```sql
CREATE TABLE posts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    source TEXT NOT NULL,           -- 来源站点: acgyxj/acgrx/acgll
    source_id TEXT NOT NULL,        -- 原站帖子ID
    source_url TEXT NOT NULL,       -- 原帖链接
    title TEXT NOT NULL,            -- 标题
    platform TEXT DEFAULT 'unknown', -- 平台: pc/android/pc_android/unknown
    content TEXT,                   -- 正文内容(纯文本)
    likes INTEGER DEFAULT 0,       -- 点赞数
    comments INTEGER DEFAULT 0,    -- 评论数
    views INTEGER DEFAULT 0,       -- 浏览量
    unzip_code TEXT,               -- 解压码
    cheat_code TEXT,               -- 作弊码/解压步骤
    baidu_link TEXT,               -- 百度网盘链接
    baidu_code TEXT,               -- 百度提取码
    mobile_link TEXT,              -- 移动云盘链接
    mobile_code TEXT,              -- 移动云盘提取码
    images TEXT,                   -- 图片JSON数组(本地路径)
    original_images TEXT,          -- 原始图片URL JSON数组
    crawled_at TIMESTAMP,          -- 爬取时间
    post_date TEXT,                -- 原帖发布时间
    UNIQUE(source, source_id)      -- 防重复
);
```

### tasks 表
```sql
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_type TEXT NOT NULL,        -- by_date / by_page
    params TEXT NOT NULL,           -- 任务参数JSON
    status TEXT DEFAULT 'pending',  -- pending/running/completed/failed/cancelled
    total_posts INTEGER DEFAULT 0, -- 总帖子数
    success_posts INTEGER DEFAULT 0, -- 成功爬取数
    skipped_posts INTEGER DEFAULT 0, -- 跳过数(无网盘链接)
    error_posts INTEGER DEFAULT 0, -- 失败数
    started_at TIMESTAMP,
    finished_at TIMESTAMP,
    created_at TIMESTAMP
);
```

## 四、各网站爬取策略

### 1. ACG游戏姬 (acgyxjvip.com)
- **列表页**: `https://www.acgyxjvip.com/page/{N}` (共2560页)
- **详情页**: `https://www.acgyxjvip.com/{id}.html`
- **互动数据**: 列表页直接有浏览量(`span.list-post-view`)和评论数(`span.list-post-comment`)
- **图片**: 懒加载，从 `data-src` 属性提取
- **分页**: `/page/N` 格式
- **按日期爬取**: 需要从详情页获取发布日期，列表页无日期信息

### 2. 萌幻ACG (bbs4.acgrx.com)
- **列表页**: `https://bbs4.acgrx.com/page/{N}` (共596页，第1页为根路径)
- **详情页**: `https://bbs4.acgrx.com/game/{id}.html` 等
- **互动数据**: 列表页无任何互动数据，详情页可能有
- **图片**: 懒加载，从 `data-original` 属性提取
- **登录**: 需要自动登录才能查看详情页内容
- **分类**: 游戏(game)/动画(anime)/漫画(manga)等，只爬游戏分类
- **按日期爬取**: 列表页有 `data-timestamp` 属性

### 3. ACG图书馆 (acgll.xyz)
- **分类页**: `https://acgll.xyz/category/youxi/page/{N}` (共2283页)
- **详情页**: `https://acgll.xyz/{slug}`
- **互动数据**: 需AJAX加载或从分类页获取
- **图片**: 懒加载，从 `data-src` 属性提取
- **隐藏内容**: 跳过，只抓公开内容
- **按日期爬取**: 需从详情页获取发布日期

### 4. ACG俱乐部 (acgjlb.cc)
- **列表页**: `https://www.acgjlb.cc/acggame` (共12385篇)

- **标签**: SLG/RPG/ADV/ACT/3D/日系/欧美/国产
- **排序**: 发布/更新/浏览/点赞/评论/收藏
- **按日期爬取**: 需从详情页获取发布日期

### 4.5 鲲Galgame (kungal.com) —— 2026-09-23 新增，同日改为 API 全量爬取
- **四个接口**（前三个公开，第四个需登录 cookie）：
  1. 列表 `GET /api/galgame?include_providers=baidu,caiyun&page={N}&limit=20`
     - `include_providers=baidu,caiyun` = 含百度网盘或和彩云(移动云盘)资源的游戏（约3400个），服务端预过滤
     - **坑**：参数必须 snake_case；驼峰 `includeProviders` 会被静默忽略（total 不变、不过滤）
  2. 游戏详情 `GET /api/galgame/{gid}` → `name` / `name_original` / `alias[]` / `effective_banner_url` / `intro_text` / `view` / `like_count`
  3. 资源列表 `GET /api/galgame/{gid}/resource/all?galgame_id={gid}` → 每条资源：`provider_names[]`（"百度网盘"/"和彩云 (移动云盘)"）、`platform`(windows/app/emulator)、`platforms[]`(win/and)、`size`、`status`(0有效/1失效)、`note`、`created`、`user`
  4. 下载详情 `GET /api/galgame-resource/{rid}/detail?galgame_resource_id={rid}` → `link[]`（真实链接）、`code`（提取码）、`password`（解压密码）、`note`
     - **未登录返回 401 `{"code":205,"message":"用户登录失效"}`**
     - 注：`/api/galgame/{gid}/resource` 等路径即使带 cookie 也返回 500，别用；正确路径是 `galgame-resource/{rid}/detail`
- **登录态**：账号是 NextMoe·未萌 OAuth（`account.nextmoe.com`），站点自己不再有账密登录。会话 cookie `kungal_session`（约90天滑动有效）写在 `.env` 的 `KUNGAL_COOKIE`；`KUNGalgameUser` cookie 里带 `nsfwDisplay:"show"`，即"设置-内容-显示"跟着账号走
  - 刷新方式：内置浏览器打开 kungal → 右上"登录" → 弹窗"登录" → NextMoe 授权页"登录后继续" → 填账号密码 → 登录后取 `cookies get` 里的 `kungal_session` 写回 `.env`
- **挑选规则**：只保留百度网盘 / 和彩云；在"有效(status==0)"资源里按 `created` 各取最新一条（页面默认排序不是按时间，不能直接用第一条）；两类都没有 → 该游戏跳过
- **标题/平台**：`主名 + 【平台】`（2026-09-23 用户确认去掉大小——各网盘体积改到备注的"网盘大小"行，因为百度与移动常是不同的打包版本，标题只写一个会误导）；平台由所选资源 `platforms` 推得（win→PC、and→安卓、都含→PC+安卓、emulator→PC+安卓、mac→PC）
- **备注结构**（`_build_content`）：`网盘大小：百度网盘 x ｜ 移动云盘 y`（**放第一行**，否则长别名会把它挤到折叠线以下）→ `别名：<原名并入同一行>` → `【百度网盘 发布者备注】`→`【移动云盘 发布者备注】`→`【简介】`（总长截 5000）
- **别名**：`name_original` + `alias[]` 写入正文，不进标题
- **解压密码**：取 `password` 字段进 `unzip_code`，**按网盘标注**（`百度网盘 open ｜ 移动云盘 afggacg`；两盘同码合并为 `百度网盘/移动云盘 CC`；单盘则只写该盘）；备注里"解压密码"那一行自动删除并重排序号，避免重复与删行留空
- **备注(note)**：动态原样保留（改后缀/解压工具/文件说明因发布者而异），仅轻度清理 markdown 标记（`**`、`###`、`> `、`[](url)`），语义不变
- **封面**：只取 1 张主封面 `effective_banner_url` 并下载到本地
- **下载按钮**：一条资源同时支持 PC/安卓时，`download_items_json` 出两条（平台分别 pc、android），与导出卡片渲染一致；`code` 为空时从链接 `?pwd=` 兜底
- **验证**：第1-2页 40 个游戏 → 40 入库 / 0 跳过 / 0 失败
- **覆盖范围**：该列表不区分平台，含"电脑 / 安卓 / 电脑+安卓"全部游戏（登录态 total≈6840，342 页）；平台在解析时按所选资源的 `platforms` 划分，导出与结果页按 PC / PC+安卓 分组（安卓并入 PC+安卓，沿用既有约定）
- **末页坑**：列表末页返回空 JSON（<200 字符），会被 `BaseCrawler._request()` 的"验证页检测"误判成拦截页并抛错 → kungal 改为自己发请求（`_api`），不套用该启发式
- **cookie 维护**：`tools/refresh_kungal_cookie.py` 一键重新登录并刷新 `.env: KUNGAL_COOKIE`（读 `NEXTMOE_NAME` / `NEXTMOE_PASSWORD`）；cookie 是 90 天**滑动**有效，期间爬过就自动续期
  - 已挂定时任务「刷新鲲Galgame登录cookie」：每 60 天自动运行一次（首次 2026-11-22 09:00），跑完会报告 cookie 是否可用
  - 脚本坑：不能让 agent-browser 的输出接管道（浏览器 daemon 会继承句柄，`subprocess` 永远等不到 EOF）→ 输出丢弃、需要输出时写临时文件再读

### 4.6 卡片「备注」折叠（2026-09-23 新增，主界面 + 导出 HTML）
- ★ **仅鲲Galgame 的卡片显示备注块**（2026-09-23 修正）。四站是管理员整理型站点，`posts.content` 装的是**游戏简介**，不属于备注；鲲是用户发帖型，用户会写改后缀/解压工具等说明，才叫备注
  - 判定条件（两处都要）：`generator/__init__.py` 用 `post.get("source") == "鲲Galgame"`；`static/app.js` 用 `post.source === "鲲Galgame"`
  - ⚠️ **必须用中文名**：`source` 字段存的是中文（`鲲Galgame`），写成英文 key `kungal` 判定永久不成立（曾踩坑，导致鲲备注全不显示）
- 数据源是 `posts.content`（鲲：别名 + 各网盘大小 + 发布者备注 + 简介），卡片默认显示 3 行，超出才显示「展开」按钮
- 按组件库「文本展开」条目实现：**展开高度取实测值**（不用固定 max-height 猜高度），动画收尾后清掉内联 `max-height`；箭头 `rotate(180deg)` 与状态同步；`aria-expanded` + `aria-label`（展开备注/收起备注）；原生 `button` 保证键盘可触发；`prefers-reduced-motion` 下不做动画
- 卡片初始位于折叠分组内时高度量到 0 → 用 IntersectionObserver 在真正可见时再判定是否显示按钮；`[hidden]` 需显式写 `display:none`，否则会被 `.note-toggle{display:inline-flex}` 覆盖
- **整块点击复制**：备注体带 `data-copy`（完整备注，不是被截断的显示文本），点击复制并给"已复制"反馈（`.card-note.copied-note` / `.copy-text.copied`）

### 4.8 导出拆分：三份 HTML（2026-09-23 变更）
- `generator.export_posts()` 现在产出 **PC下载 / PC+安卓下载 / 安卓下载** 三份 HTML+zip
  - `pc` = `platform in ('pc','unknown')`；`pc_android` = `platform='pc_android'`；`android` = `platform='android'`
  - 三类互不重叠（单安卓不再并入 PC+安卓）；某类为空则该 key 返回 `""`，不生成 zip
  - 返回值仍带 `mixed` 键（= pc_android）以兼容旧调用
- 平台过滤口径同步收紧，涉及 4 个查询函数 + `app.py` 的 `_export_filter_conditions` / `_filtered_post_count` / `_fetch_filtered_posts`：`pc` 含 unknown；`pc_android` 只含 pc_android；新增 `android`
- 前端：结果页平台页签加「安卓」；分组头带 `data-plat` 供取色；任务历史加「本批次安卓」；导出面板加第三张卡片（`countAndroid`）
- `GET /api/export_counts` 返回 `{pc, pc_android, android, mixed}`

### 4.9 视觉系统：Origin 深色编辑风（2026-09-23 全站替换）
- **表面色阶代替投影**：`abyss #090a0b`（日志/批次）→ `obsidian #0f1011`（画布）→ `graphite #2e2e2e`（卡片）→ `steel #3f4041`（hover）→ `silver #cacaca`（反转面，未用）；**卡片无 box-shadow**
- **三声部字体**：`--font-display`（Playfair Display / Noto Serif SC）仅用于标题与统计大数字，weight 300、行高 0.9-1；`--font-ui`（Geist / Inter）做正文与控件；`--font-mono`（Roboto Mono）做所有标签、徽章、数据，**大写 + 0.182em 字距**
- **彩色使用规则**：iris / cyan / orchid / deep-iris 只用于满幅「分类色块」（平台分组头 `.date-group-header[data-plat]`、导出卡片 `.export-card:nth-child(n)`）；cyan 仅作数据信号（进度条、成功徽章）；**禁止彩色小字**
- **主操作 = 白底黑字**（`.btn-primary` 带 `→`）；次操作幽灵描边；输入框黑底 + 1px rgba(255,255,255,0.1)；芯片统一胶囊（白色 12% 底 + 15% 描边）
- 顶栏：吸顶 + `backdrop-filter: blur(24px)`；`h1::before` 输出等宽大写眉标
- 已删除：紫粉渐变 `--grad-1/--grad-2`、发光色 `--accent-glow`、Emoji 统计、卡片阴影与缩放悬浮
- 断点：900px（侧栏横向化）、560px（收紧字号与内边距）、`prefers-reduced-motion`
