## 2026-09-23 v16 修复：四站误加备注块 + 多图被挤压

### 改了什么

1. **卡片「备注」块限定为仅鲲Galgame**（主界面 + 离线导出 HTML 两处）
2. **卡片图片网格恢复多图平铺**（主界面 + 离线导出 HTML 两处 CSS）

### 为什么

- **备注块问题**：v11 新增「备注折叠」时，条件只写了 `if note_text`（有正文就渲染），**没加站点判断**。四个老站的 `content` 字段装的是**游戏简介**（管理员整理的介绍文字），于是被这个通用条件套上了"备注"壳，卡片上多出备注块。用户原话："其他站点根本就没有备注，因为是管理员发的、有做整理的，只是这个新添加的站点是以用户为主"。
- **图片问题**：v14 换 Origin 风格时，把图片网格从 `repeat(auto-fill, minmax(120px,1fr))` + `max-height:250px` 改成了 `repeat(auto-fit, minmax(120px,1fr))` + `height:220px`（**去掉 max-height**）。结果多图被压成一条、视觉上"只剩一张图"。用户原话："我记得其他站点之前是很多图片的，不是一张"。**经查数据库，图片一张没少**（图书馆平均 3.8 张、游戏姬 4.7 张、萌幻 12.1 张），是布局坏了。

### 之前 → 现在

**备注块判定**

```python
# 之前（错误）：四站也会显示备注
note_text = (post.get("content") or "").strip()
if note_text:

# 现在（正确）：只给鲲Galgame
if note_text and post.get("source") == "鲲Galgame":
```

```javascript
// 之前（错误）
if (noteText) {
// 现在（正确）
if (noteText && post.source === "鲲Galgame") {
```

> ⚠️ 中间踩坑：第一版写成 `== "kungal"`（英文 key），**永久不成立**（数据库 `source` 存的是中文 `鲲Galgame`），导致鲲的备注全都不显示。已修正为中文名。

**图片网格 CSS**（`generator/__init__.py` 的 `HTML_TEMPLATE` 与 `static/style.css` 两处）

```css
/* 之前（v14 起，错误） */
.card-imgs { grid-template-columns: repeat(auto-fit, minmax(120px,1fr)); gap:1px; }
.card-imgs img { height: 220px; object-fit: cover; }

/* 现在（恢复正确） */
.card-imgs {
    grid-template-columns: repeat(auto-fill, minmax(120px, 1fr));
    gap: 1px;
    overflow: hidden;
    max-height: 250px;
}
.card-imgs img { width:100%; height:100%; min-height:110px; object-fit:cover; display:block; }
.card-imgs:has(img:nth-child(1):last-child) img { height:280px; min-height:280px; }
```

### 涉及文件

| 文件 | 改动 |
|------|------|
| `acg_crawler/generator/__init__.py` | 备注条件加 `source == "鲲Galgame"`；`card-imgs` CSS 恢复 |
| `acg_crawler/static/app.js` | 备注条件加 `post.source === "鲲Galgame"` |
| `acg_crawler/static/style.css` | `.card-images` CSS 恢复（主界面类名是 `card-images`，不是 `card-imgs`） |

### 验证

重新导出全库 974 条 / 415 张卡片（`output/PC+安卓下载-20260923-152733/`）：

| 检查项 | 结果 |
|--------|------|

| 截图核对 | 四站卡片=标题/平台/链接/解压码，无备注块；多图平铺 ✅ |

## 2026-09-23 v15 鲲Galgame 备注引流清洗（通用规则）+ 审计日志

### 改了什么
- 新增 `crawler/kungal.py` 的 `_is_promo_line()` / `_promo_rule()`：**按特征组合识别**引流内容，不背具体句子
- 新增 `_collapse_numbered_groups()`：编号列表整组连同引导句丢弃

- 新增审计日志 `logs/promo_clean/YYYY-MM-DD.jsonl`（记 `removed` + `suspect`）

## 2026-09-23 v14 导出拆三份 + 全站换 Origin 深色编辑风

### 改了什么
1. **导出拆成 3 份**：`PC下载` / `PC+安卓下载` / `安卓下载`（单安卓不再并入 PC+安卓）
2. **全站视觉换成 Origin 深色编辑风**（主界面 + 离线导出 HTML）

### 为什么
- 拆分：用户需要单独一份「安卓」导出
- 换风格：用户要求换掉原来的粉紫渐变主题

### 之前 → 现在

**导出**
- 之前：PC + PC+安卓 两份（安卓归入 PC+安卓）
- 现在：PC / PC+安卓 / 安卓 三份，互不重叠，`unknown` 归 PC，某类为空不生成

**视觉（★重点，用户最关心）**

| 项 | 之前（粉紫渐变） | 现在（Origin 深色编辑风） |
|----|-----------------|------------------------|
| 主色 | `--accent: #e056a0`（粉红） | `--accent: var(--pure)`（白），彩色只做分类色块 |
| 渐变 | `--grad-1: linear-gradient(135deg,#e056a0,#8b5cf6)`（粉→紫） | **删除渐变** |
| 底色 | `#08080c` / 面板 `#0e0e14` / 卡片 `#14141e` | `abyss #090a0b` → `obsidian #0f1011` → `graphite #2e2e2e` → `steel #3f4041` |
| 卡片 | `hover` 上浮 `translateY(-3px)` + `box-shadow`，圆角 12px | **无投影、无上浮**，靠表面色阶分层 |
| 字体 | `Inter / SF Pro Display / 微软雅黑` | 三声部：衬线(标题) / 无衬线(UI) / 等宽(标签，大写+0.182em) |
| 顶栏 | 实色 `--bg-primary` | 吸顶 + `backdrop-filter: blur(24px)` |
| 强调色 | 粉色小字、发光描边 | **禁止彩色小字**；彩色仅用于满幅分类色块 |
| 导出 HTML | body `#0a0a0f`，header 渐变 `#1a1a2e→#16213e`，h1 `#4fc3f7` | 与主界面同一套 Origin 变量 |

> ★ **旧风格完整源文件已存档**：`docs/风格存档/旧版-粉紫渐变/`（含切回方法）。
> 存档原因：用户事后想换回旧风格，但当时**没有记录**，导致无法回退。
