# 版本说明

## v4.2.7 磁盘空间分析 + 数据库优化（2026-03-26）

### 改进内容
1. **磁盘空间分析**：统计 images/data/output 三目录占用，帮助用户识别数据增长趋势
2. **数据库索引优化**：为 posts 表创建 source、platform、post_date、crawl_id、source_url 索引，加速分页查询和统计
3. **任务 ID 裁剪**：导出任务列表不再显示完整 UUID，仅显示前 8 位，界面更清爽

### 如何执行
```
python _patch17.py
```

### 数据占用分析
```
images/    约 2-3 GB（图片文件，随爬取增长）
data/      约 16 MB  （数据库，增长缓慢）
output/    可能数 GB  （多次导出的积累）
```

**释放空间建议**：
- `output/` 目录可定期清理，不影响爬取
- 如需长期保留，可将 output 移至其他磁盘
- 图片是主要占用，可通过"全选删除"定期清理不需要的帖子

## v4.2.6 批量删除 + 交互优化（2026-03-26）

### 改进内容
1. **批量删除**：帖子列表支持全选、多选，一键删除选中帖子及对应图片
2. **取消导出后不跳页**：导出/删除操作后保持当前页码，不重置到第1页
3. **图片懒加载**：列表页图片使用 `loading="lazy"`，减少初始加载压力
4. **Export id 显示优化**：任务列表的导出 id 改为 8 位短码

### 执行步骤
```
python _patch16.py
```
